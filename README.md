# UPUTSTVO

## Potrebno:
1. **.NET 9.0**
2. **Node.js**
3. **Docker Desktop**

## Pokretanje:
1. **Pozicioniranje u folder ../backend i komanda docker-compose up -d**
2. **Pozicioniranje u folder ../backend/API i komanda dotnet run**
3. **Pozicioniranje u folder ../frontend i komanda npm run start**
